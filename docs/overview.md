# Kubera

## Overview

Project Kubera aims to help its users with financial tracking and recommendations.

## Features

Primary features of Kubera are as follows:

- [Log Expenses](/docs/features/log-expenses.md)
- [Expense Categorization](/docs/features/expense-categorization.md)
- Category budgeting
- Wishlist
- Saving estimation
- Notification and threshold-based alerts on expenses
- Export data to CSV

Future features to come:
- Education financial recommendations
- Multiple device sync
